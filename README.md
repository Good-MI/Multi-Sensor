**Multi Sensor** App adalah aplikasi Android yang memanfaatkan tiga sensor bawaan HP untuk menghadirkan pengalaman interaktif secara real-time.

- **Motion Sensor:** Menggerakkan bola sesuai kemiringan HP, dilengkapi suara beep dan getaran saat bola menabrak dinding dengan keras.
- **Compass Sensor:** Menampilkan arah mata angin dan derajat secara real-time menggunakan sensor magnetik dan gerakan HP.
- **Light Sensor:** Mengubah tema aplikasi secara otomatis antara Light Mode dan Dark Mode sesuai kondisi cahaya sekitar, dengan pilihan pengaturan manual.
